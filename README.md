# pogo.bizcrafters.com

Static GPX route site on GitHub Pages. `routes.json` is the list of routes, `gpx/` holds the files,
`index.html` is generated by `build/index.py`. Credits are in `CREDITS.md`.

## Add routes from a Discord paste (no Claude needed)

1. Open https://github.com/mallek/bizcrafters-site/issues/new?template=add-route.md (works in the phone browser).
2. Paste the whole Discord text under the comment line and submit.
3. A workflow parses it, adds one route per heading, commits, and replies on the issue with map and GPX links.
   The site updates in a minute or two.

Format: a heading line, then lines like `19.4350330, -99.1413480`. Markdown, emoji, "(Click to Copy)", dates and
blank lines are ignored. Several headings in one paste make several routes. Submitting the same heading again
replaces that route. If nothing is found, the bot says so; edit the issue to try again.

Optional: put a name in the title, like `Add route: Reforma Gengar`, to combine everything in the paste into one route
with that name. Leave the title as `Add route` to get one route per heading.

Only issues opened or edited by the repo owner are processed.

Local use: `python3 build/add_routes.py --site . --body-file paste.txt`.
